# 🛍️ Retail Sales Analysis & Forecasting
This project explores retail sales data to uncover trends and forecast future performance using time series analysis.

## 📂 Project Highlights
- 📊 Exploratory Data Analysis (EDA)
  - Monthly Sales Trends
  - Sales by Category, Region, Segment
  - Top-Selling Products

- 🔮 Time Series Forecasting
  - 90-day revenue forecast using Facebook Prophet
  - Exported results to Excel
  - Seasonality & trend components analyzed

## 📁 Files Included
- `Retail_Sales_Analysis_and_Forecasting-2.html` – Code + Visuals (viewable in browser)
- `Retail_Sales_Analysis_and_Forecasting-PDF.pdf` – Full Project Report
- `*.jpeg` – Visuals (bar charts, time series, forecast)

## 🧰 Tools Used
- **Python**: Data manipulation and visualization with `pandas`, `matplotlib`
- **Prophet**: Time series forecasting
- **Jupyter Notebook**: Interactive analysis
- **Excel**: Export final forecasts


## 📈 Results
- Revenue is growing across months, especially Q4
- Technology leads in category sales
- Forecast predicts upward trend over next 3 months

## ✅ Business Recommendations
- Increase marketing in West region
- Focus on Technology & Office Supplies
- Align promotions with forecasted peak periods
